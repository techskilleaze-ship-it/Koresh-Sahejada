# Koresh Sahejada — Chef Portfolio

Static site. No build step.

- `index.html` — the page
- `support.js` — runtime the page needs (keep next to index.html)
- `assets/` — photos

## Publish on GitHub Pages
1. Push these files to the root of a repo.
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. Site goes live at `https://<username>.github.io/<repo>/`.

To preview locally, serve the folder (e.g. `npx serve .`) rather than double-clicking index.html.
